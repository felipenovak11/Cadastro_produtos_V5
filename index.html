    O que é Bootstrap?

    Bootstrap é um framework gratuito de HTML, CSS e JavaScript que traz componentes prontos (botões, modais, avisos, grades) para criar telas bonitas e responsivas sem escrever tudo do zero.

    Neste projeto ele cuida de:

    • Toasts: avisos rápidos de sucesso, erro e alerta.
    • Modais: janelas de confirmação ao remover produtos.
